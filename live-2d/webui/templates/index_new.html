Motion and expression mode

Auto expressions combine face changes live. Classic motions use existing motion files. AI choreography uses the new motion system. Without a separate choreography API, the current chat model is used. Modes with AI choreography turn it on. The classic motion mode turns it off.
A preset sets the VAD personality baseline, idle motion frequency, gaze steadiness and motion size in one go. The other two modes are not affected. Choreography calibration page (while the app runs): http://127.0.0.1:3002/choreo/calibration
